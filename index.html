      02 · Finishes
      
One drawing, two finishes

      
Each icon is drawn once on the grid. Both finishes come from that single drawing, so outline and duo-tone always line up.

    

    

      

        

        
Outline

        
    
          
  • Every stroke is a glass tube: frost face, accent core, specular rim and a soft shadow.
    • 
          
  • Layers are drawn across all strokes at once, so crossings fuse like one piece of glass.
    • 
          
  • Best for resting states, toolbars and dense UI.
    • 
        

      

      

        

        
Duo-tone

        
    
          
  • Filled glass. Bodies get a frost face, accent edge, glass rim and an inset accent core.
    • 
          
  • Glyphs such as !, text lines and dots are inlaid into the core as light glass tubes, tinted by the same colour.
    • 
          
  • Secondary parts like handles and trays are clear frost glass, which is the second tone.
    • 
        

      

    

  


  

    

      03 · Colour and themes
      
One colour drives the whole set

      
Icons paint from currentColor. Set color on an icon, or --sfi-color on any ancestor, and every gradient follows. For dark UIs, the themes in tokens.css also retune the frost.

    

    

    

  


  

    

      04 · Sizes
      
Sharp from 16 to 96 pixels

      
The grid is 48 units, so 24 px renders on an exact half grid. One stroke weight and 6 units of clear space between parallel strokes keep the glass from welding at small sizes.

    

    

  


  

    

      05 · Icons
      
All 136 icons

      06 · Get started
      
Install, register, use

      
No dependencies and no build step. Pick the entry that fits your stack.

    

    

      
1. Install

        
npm i soft-frosted-icons

        
Or load it straight from a CDN with no build at all:

        
<script type="module" src="https://cdn.jsdelivr.net/npm/soft-frosted-icons/src/define.js"></script>

      

      
2. Web component (any framework)


import "soft-frosted-icons/define";
import "soft-frosted-icons/tokens.css"; // optional themes


<frosted-icon name="bell"></frosted-icon>
<frosted-icon name="bell" finish="duo" size="32"
  color="#e11d48" label="Notifications"></frosted-icon>

      

      
3. React


import { FrostedIcon } from "soft-frosted-icons/react";

<FrostedIcon name="bell" finish="duo" size={24} />

        
React is an optional peer dependency, and only this entry imports it.

      

      
4. SVG strings (SSR, Vue, Svelte, Node)


import { iconSVG } from "soft-frosted-icons";

iconSVG("bell", { finish: "duo", size: 24 });
// → '<svg …>' — runs in Node, no DOM
